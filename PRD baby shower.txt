# Product Requirements Document (PRD)

# Baby Shower RSVP & Gift Registry

**Version:** 2.0
**Project Owner:** Mark Rodriguez
**Backend:** Convex
**Frontend:** React + TypeScript + Tailwind CSS + shadcn/ui
**Deployment:** Vercel / Lovable
**Target Users:** Baby shower guests and event organizers

---

# 1. Project Overview

Develop a modern, elegant, and mobile-first Baby Shower website that serves as a digital invitation, RSVP system, and online gift registry.

The website should eliminate paper invitations, prevent duplicate gifts, automatically organize RSVPs, and provide a seamless experience through a QR code that guests can scan.

The project must use **Convex** as the backend database to enable real-time synchronization of RSVPs and gift reservations.

# 17. Acceptance Criteria

The project will be considered complete when:

* Guests can access the invitation by scanning a QR code.
* RSVP submissions are stored in Convex and appear in the admin dashboard without page refresh.
* Gift reservations are stored in Convex and immediately update the availability status for all visitors.
* The system prevents duplicate reservations through backend validation.
* Administrators can manage event details, gifts, and RSVPs from a secure dashboard.
* Guests can download the event QR code and add the event to their calendar.
* The website is fully responsive, accessible, and optimized for modern browsers on Android, iPhone, tablet, and desktop.
